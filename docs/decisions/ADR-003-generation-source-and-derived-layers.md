# ADR-003：生成原图、蒙版与派生图层分离

- 状态：已接受
- 日期：2026-08-14

## 背景

图像编辑模型返回的是包含场景的完整 RGB 画面，而 CaveSky 的元素层和交互层需要可单独合成。若直接把完整画面称为“交互层”，会重复背景，并混淆元素关键帧、交互关键帧和蒙版的归属。付费生成的未采用候选也必须可追溯。

## 决策

1. 每次生成任务永久归属到唯一的目标类型、目标 ID 和关键帧 ID；所有返回候选均作为生成原图保留，无论是否采用。
2. 元素关键帧与交互关键帧各自拥有图片、蒙版、候选历史和查看状态，不共享业务数据。
3. Qwen 返回的完整 RGB 图片是“生成原图”，不是透明图层。
4. 可合成图层由生成原图与该关键帧自己的蒙版派生；仅图层和场景合成都必须应用蒙版。
5. 没有蒙版时可以查看生成原图，但不得把它标示为已分离图层。
6. 生成记录保持供应商中立；模型名称只存在于生成记录与 Adapter 层，不进入关键帧通用字段。

## 结果

- 原始元素资产不会因交互生成而改变。
- 人物与物品的联合结果只在交互区间作为派生层覆盖相应成员。
- 刷新或重新进入关键帧后仍可查看历次候选。
