# ADR-004：交互退出行为

- 状态：已接受
- 日期：2026-08-14

## 背景

交互层在区间结束时直接消失，会让拿起、穿戴或持续持有的物品跳回交互前状态。联合生成结果也不一定适合立即拆回多个独立元素。

## 决策

交互组保存供应商中立的 `exit` 状态，支持：

- `restoreIndependent`：结束后恢复成员独立轨道；
- `keepMerged`：继续显示联合层；
- `attachToMember`：继续显示联合层，并记录一个成员附着到另一个成员及语义锚点；
- `hideMember`：结束后隐藏指定成员。

交互出口最后一个已确认视觉状态作为退出快照。`keepMerged` 与 `attachToMember` 在后续交互接管前持续使用该快照；不要求立即执行有损拆层。

## 结果

交互结束不会自动跳回旧姿势，后续动作可以复用上一次联合状态作为上下文。附着锚点是作者语义，不引入骨骼或供应商字段。
