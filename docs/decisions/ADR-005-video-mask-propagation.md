# ADR-005：过渡原视频与动态蒙版分离

- 状态：已接受
- 日期：2026-08-14

## 背景

首尾帧视频模型返回完整 RGB 视频，其中包含被模型重新绘制的背景。若直接覆盖镜头画布，会破坏锁定背景；静态关键帧蒙版也无法跟随交互成员在视频中的运动。

## 决策

1. 模型返回的视频永久视为“生成原视频”，不得直接等同于交互动画层。
2. 已采用过渡可以生成独立的逐帧动态蒙版；动态蒙版属于生成版本的派生输出，不进入通用过渡字段。
3. 镜头合成使用原视频与动态蒙版派生的交互动画覆盖锁定场景；没有动态蒙版时只允许查看生成原视频。
4. 本地 6 GB 显存模式优先使用低分辨率代理、单对象和短分块处理，结果随生成版本落盘，播放时不占用 GPU。
5. 编辑器分别提供镜头合成、仅交互动画、动态蒙版和生成原视频视图。

## 结果

- 模型可以继续看到完整空间参考，但其重绘背景不会进入正式合成。
- 动态蒙版可以独立重算和修正，不需要重新支付视频生成费用。
- 后续可替换为其他视频分割或抠像模型，而不改变镜头核心格式。
