# ADR-001：本地优先、元素时间轴与可替换模型适配器

- 状态：已接受
- 日期：2026-08-13

## 背景

完整镜头直接生成难以稳定控制角色、物品、连续性和局部修改成本。传统动画软件的专业轨道系统又会让独立创作者承担过高的操作复杂度。

## 决策

1. CaveSky 以元素及其时间轴作为基本编辑单位。
2. 作者设置视觉关键状态和自然语言动作意图。
3. 简单位移、缩放、旋转和透明度变化优先使用确定性插值。
4. 接触、形变和复杂表演通过临时交互组联合生成。
5. AI 只能修改任务明确授权的元素、区域和时间区间。
6. 工程数据采用本地文件优先，并与具体模型供应商解耦。
7. VACE、SAM、RIFE 等能力通过 Adapter 接入，可以替换或组合。

## 结果

优点：

- 作者拥有明确控制权。
- 可以局部重做而不重生成整个镜头。
- 演员、场景和物品能够跨镜头复用。
- 模型升级不会迫使工程格式整体迁移。

代价：

- 需要维护合成、蒙版、坐标和时间的一致性。
- 交互组边界和上下文策略需要经过实际生成实验验证。
- 需要把“确定性编辑”和“生成式编辑”清楚地区分在界面中。

## 不采用的方案

- 仅通过完整视频提示词生成整个镜头：连续性和局部重做能力不足。
- 完整复制传统动画软件的复杂轨道系统：学习成本和开发成本过高。
- 将工程格式绑定单一模型：会产生供应商锁定和迁移成本。
